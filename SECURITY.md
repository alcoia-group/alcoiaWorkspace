# Security policy

Report vulnerabilities privately. Do not open a public issue.

## How to report

1. Use GitHub's private vulnerability reporting: go to the repository's **Security** tab and choose **Report a vulnerability**.
2. If you cannot use GitHub, email hello@alcoia.app with "Security" in the subject line.

Include the affected page or file, the browser and version, steps to reproduce, and what an attacker could do with it.

## Scope

In scope: the web app in this repository.

Out of scope:

- Services this app talks to, which are separate and private. If you find an issue in one of them, send it through the same channels above and we will route it.
- Third-party code and fonts. Report those upstream (see [`NOTICE.md`](NOTICE.md)).
